Cost Allocation Tab – UI and Workflow Enhancement
The current UI contains repetitive fields and cards, making it cluttered and less user-friendly. Redesign the interface with the following structured approach:

Display Budget Items:
Show all budget line items selected by the user in the 'Budget Item Selection' tab in a clean tabular format.

Include a short, editable description for each budget line item.

Each row should be clickable to enter the allocation workflow.

Allocation Workflow for Budget Items:

Allow the user to enter input values and select a unit of measurement (e.g., area, labor, time, load).

Note: Each budget line item can only have one type of unit.

Support multiple inputs per budget line item.

Let the user select a ratio from a dropdown list. The options should be sourced from the ratios available in the Ratio Management tab.

For each input:

Multiply the input value with the selected ratio

Allocate the proportion to the relevant entities accordingly.

Aggregate the total allocations per entity across all inputs to generate the final distribution for the budget line item.

Allocation Summary Tab Integration:

Ensure that the calculated allocations are reflected in the Allocation Summary tab.

Update the report structure to include the refined allocation details based on the new logic.
